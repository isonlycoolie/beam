# Support

Beam is early open-source software.

Use GitHub issues for:

- Reproducible bugs.
- Documentation gaps.
- Feature requests for the local CLI, core, or MCP server.

When reporting a bug, include:

- Beam version or commit.
- Node.js and pnpm versions.
- Command run.
- Redacted output.
- Whether live Figma credentials were used.

Do not paste Figma tokens, private file contents, or customer design data into issues.
