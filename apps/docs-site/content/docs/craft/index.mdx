Generated UIs look alike: everything centred, purple gradients, gradient headline text, emoji bullets, a dozen font sizes and padding that is never quite even. Craft gives your agent the decisions that avoid that, and a review that catches what slips through.

```bash
npx usebeam add craft
```

<Callout title="Draft">
The Craft principles are a first version and will change as we agree them. The review measures facts, so it is ready to use today.
</Callout>

## The short version

- One typeface, two at most. Contrast comes from size and weight.
- One type scale (5 to 7 sizes) and one 4px spacing scale.
- Left-aligned reading. Centre only short headings.
- One accent colour, used on purpose.
- Fast and accessible by default.

Read the full list in [Principles](/docs/craft/principles), then run a [review](/docs/craft/review).
