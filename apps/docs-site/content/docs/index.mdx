Coding agents are fast at UI and loose with the details. Ask one to copy a page and you get something *like* it: the font is close, the spacing is rounder, the colours drift toward its favourites. You then spend the afternoon pointing at pixels.

Beam closes that gap. It measures the source, hands your agent the exact values, and checks the result against the original until it matches.

## Five tools, use any one

| Tool | What it does |
| --- | --- |
| [Clone](/docs/clone) | Rebuild any live page exactly from measured styles, real fonts and real images |
| [Figma](/docs/figma) | Turn a Figma frame into code on any Figma plan, no API token needed |
| [Craft](/docs/craft) | Build new UI that looks designed, not generated, and check its quality |
| [Glass](/docs/glass) | Apple-style liquid glass components, copied into your project |
| [Verify](/docs/verify) | Prove a build matches its source, section by section |

Each tool installs on its own. Add Clone today, Glass next month; nothing else comes along unless you ask for it.

```bash
npx usebeam add clone
```
