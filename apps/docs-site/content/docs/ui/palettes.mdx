Components stay monochrome. A palette is where colour comes in: it fills the same tokens, so switching one changes every component at once and none of their code. Hover a swatch to see its hex, click to copy it, or open a palette to see it on real components and copy its tokens.

<Palettes />

## Use a palette

```bash
npx usebeam add ui/palette-navy
```

```tsx title="app/layout.tsx"
<body data-theme="navy">
```

Every palette is generated from a neutral tint, one primary and one accent, then checked so every text pair reaches 4.5:1 contrast in light and dark. A palette that fails the check can't ship.
