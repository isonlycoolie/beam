Beam UI uses the free Stroke Rounded set from [Hugeicons](https://hugeicons.com), MIT licensed, and every icon in it is below. The other Hugeicons styles (Bulk, Solid, Twotone, Duotone, Sharp) are Hugeicons Pro: a paid licence Beam never ships or redistributes.

## Use an icon

```bash
npm install @hugeicons/react @hugeicons/core-free-icons
```

```tsx
import { Search01Icon } from "@hugeicons/core-free-icons";
import { Icon } from "@/components/ui/icon";

<Icon icon={Search01Icon} size="sm" />
```

| Size | Pixels | Stroke | Use |
| --- | --- | --- | --- |
| `sm` | 16 | 1.75 | Inside buttons, inputs, badges, table rows |
| `md` | 20 | 1.75 | Navigation and toolbars (default) |
| `lg` | 24 | 1.5 | Empty states and feature callouts |

## Rules

- Icons follow the text colour (`currentColor`), so they always match their label.
- An icon that is the only content of a button needs a label: `<Button size="icon" aria-label="Search">`.
- One icon style per product. Do not mix Hugeicons with other sets.
