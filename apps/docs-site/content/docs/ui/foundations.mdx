## Colour

Components never use raw colours. They use these tokens, and a palette fills them in. Below is Graphite, the default: greys and one black primary. Every text pair is tested to reach 4.5:1 contrast in light and dark.

<ColorSwatches />

Want colour? Pick one of the [palettes](/docs/ui/palettes). They fill the same tokens, so no component changes.

## Type

Geist and Geist Mono, the faces shadcn/ui uses. Seven steps; every size in an app comes from one of them, and a single card uses at most three.

<TypeScale />

```tsx title="app/layout.tsx"
import { Geist, Geist_Mono } from "next/font/google";

const geist = Geist({ subsets: ["latin"], variable: "--font-geist" });
const geistMono = Geist_Mono({ subsets: ["latin"], variable: "--font-geist-mono" });

<html className={`${geist.variable} ${geistMono.variable}`}>
  <body data-theme="default">
```

```css title="globals.css"
@import "@beam/ui/styles/tokens.css";
@import "@beam/ui/styles/type.css";
@import "@beam/ui/styles/tailwind.css";
@import "@beam/ui/palettes/default.css";
```

## Space, radius and motion

| Token | Values |
| --- | --- |
| Space | `--space-1` 4px up to `--space-16` 64px, on a 4px grid |
| Radius | `--radius-sm` 6, `--radius-md` 10, `--radius-lg` 14, `--radius-xl` 20 |
| Controls | 32, 36 and 40px; 28, 32 and 36px with `data-density="compact"` |
| Motion | `--dur-fast` 150ms, `--dur-base` 220ms, `--ease-out`; zero for reduced motion |
