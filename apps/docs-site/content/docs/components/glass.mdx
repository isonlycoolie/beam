Every preview in these docs has a **Normal · Glass** switch. Glass is not a second set of components: it is one attribute on any parent, and the same components turn to glass.

```tsx
<body data-surface="glass">
```

Put it on `<html>` or `<body>` when menus and dialogs should follow, since they render at the end of the page. Glass ships with Beam's tokens (`styles/beam/glass.css`); import it after `tailwind.css`.

## What turns to glass

| Tier | Components | Material |
| --- | --- | --- |
| Surfaces | Card, Sidebar, Menubar, Navigation Menu | Frosted, 24px blur |
| Overlays | Dialog, Alert Dialog, Sheet, Drawer, Popover, Hover Card, menus, Select, Command | More opaque, 40px blur, so text above other text stays readable |
| Controls | Input, Textarea, Input Group, Select trigger, Tabs, outline and secondary Button and Badge | Light frost |

Primary buttons, switches and checkboxes stay solid: they carry the action and the state.

For the iOS material with refraction (the bent edges and moving highlight), use [Liquid Glass](/docs/components/liquid-glass) and the [Tab Bar](/docs/components/tab-bar).

## Where glass belongs

- Over content: photos, video, maps, gradients, a page that scrolls underneath. On a flat background glass only looks grey.
- Floating and temporary layers: bars, toolbars, menus, sheets, one hero card.
- One layer at a time. No glass on glass.
- Short text. Contrast moves as the background moves.

## Tune it

Set these on `<html>`, a section or any element. The defaults are iOS 26's, as glisse measured them.

| Variable | Default | What it does |
| --- | --- | --- |
| `--beam-glass-frost` | `3px` | Blur behind glass. Surfaces use 3×, menus and dialogs 8× |
| `--beam-glass-rim` | `0.3` (`0.13` dark) | The line of light on every glass edge |
| `--beam-glass-tint` | `rgb(255 255 255 / 0.6)` | Cards and bars |
| `--beam-glass-surface` | `rgb(250 250 252 / 0.86)` | Menus, dialogs, popovers: denser, they float over text |
| `--beam-glass-bend`, `--beam-glass-dispersion` | `1`, `0.6` | Refraction on [Liquid Glass](/docs/components/liquid-glass) and the [Tab Bar](/docs/components/tab-bar) |

In glass mode, buttons become iOS 26 liquid buttons: the primary action is filled, the rest are clear glass, all pill-shaped, and they grow and spring back when pressed. Switching between Normal and Glass cross-fades the whole page. People who turn on "Reduce transparency" get solid surfaces automatically.
