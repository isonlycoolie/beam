shadcn/ui means nobody builds an input from scratch any more. But hand those components to an agent and you still get four cards in a row with one stranded underneath, three primary buttons, a skeleton that looks nothing like the page, and no empty state.

Beam UI fixes the second half of the problem:

- **The parts.** shadcn/ui components restyled in a calm, monochrome design, set in Geist, with the free Hugeicons set and twelve enterprise palettes.
- **The rules.** Every component ships a spec that tells agents when to use it, when not to, how long its copy can be and which layout rules apply. Beam checks the result.

## Use only what you need

| You need | Run |
| --- | --- |
| One component | `npx usebeam add ui/button` |
| A sidebar layout | `npx usebeam add ui/sidebar-icon-collapse` |
| A palette | `npx usebeam add ui/palette-navy`, then set `data-theme="navy"` |
| Icons | `npm install @hugeicons/react @hugeicons/core-free-icons` and Beam's `<Icon>` |

## Style any component the same way

Every component follows one contract, so once you know Button you know them all.

| Way | Example | Where it works |
| --- | --- | --- |
| Props | `<Button variant="outline" size="lg" className="w-full" />` | Sizes are always `sm`, `md`, `lg`; variants use the same words: `default`, `secondary`, `outline`, `ghost`, `destructive` |
| CSS hooks | `[data-slot="button"][data-variant="outline"] { … }` | Every part has a `data-slot`; sized and varied parts carry `data-size` and `data-variant` |
| Tokens | `--radius-md: 0` gives square buttons, inputs and menus | One variable restyles every component; palettes swap all colours; `data-surface="glass"` turns everything to liquid glass |

## What's here

- Components: all of shadcn/ui's set, from Button to Sidebar, on Beam's measured sizes and tokens.
- [Sidebar layouts](/docs/components/sidebars/sidebar-icon-collapse): 16 complete app sidebars, from collapsing to icons to a file tree.
- [Palettes](/docs/palettes): open-source palettes; one attribute switches every component.
- [Icons](/docs/icons): all 6,791 free Hugeicons, with install guides for every stack.
