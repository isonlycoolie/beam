Beam Icons is the free [Hugeicons](https://hugeicons.com) set: 6,791 icons drawn on a 24px grid in one style, Stroke Rounded. One set means every icon in your app shares the same stroke, corners and weight, so nothing looks borrowed.

## Get started

1. Install the package for your stack: [React](/docs/icons/installation/react), [Vue](/docs/icons/installation/vue), [Svelte](/docs/icons/installation/svelte), [Angular](/docs/icons/installation/angular), [React Native](/docs/icons/installation/react-native), or [plain SVG](/docs/icons/installation/svg).
2. Find an icon in [Browse](/docs/icons/browse), click it to copy.
3. Paste it. Icons follow the text colour, so they always match their label.

## Licence

The free set is MIT licensed: use it in any project, commercial or not. Hugeicons also sells Pro styles (Bulk, Solid, Twotone, Duotone, Sharp); those are a paid licence, and Beam never ships or redistributes them.
