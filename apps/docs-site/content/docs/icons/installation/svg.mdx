---
title: SVG
description: Use Beam Icons as plain SVG, with no framework.
---

Every icon is a 24×24 SVG with a 1.5px stroke in `currentColor`, so it takes the colour of the text around it.

1. Open [Browse](/docs/icons/browse) and set **Copy as** to **SVG**.
2. Pick a weight: 1, 1.5 (default) or 2.
3. Click an icon and paste it into your HTML.

```html
<button class="search">
  <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none">
    <path d="M17 17L21 21" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round"/>
    <path d="M19 11C19 6.58172 15.4183 3 11 3C6.58172 3 3 6.58172 3 11C3 15.4183 6.58172 19 11 19C15.4183 19 19 15.4183 19 11Z" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round"/>
  </svg>
  Search
</button>
```

Set the size with `width` and `height`, and the colour with CSS `color` on the parent.
