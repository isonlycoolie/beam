## Use an icon

`react-native-svg` is a peer dependency. Expo includes it; in a bare React Native app, follow the [react-native-svg setup](https://github.com/react-native-svg/react-native-svg#installation).

```tsx title="App.tsx"
import { View } from "react-native";
import { HugeiconsIcon } from "@hugeicons/react-native";
import { Search01Icon } from "@hugeicons/core-free-icons";

export default function App() {
  return (
    <View>
      <HugeiconsIcon icon={Search01Icon} size={20} color="#0f0f0f" strokeWidth={1.5} />
    </View>
  );
}
```

Every icon in [Browse](/docs/icons/browse) works the same way: copy its name and pass it as `icon`.
