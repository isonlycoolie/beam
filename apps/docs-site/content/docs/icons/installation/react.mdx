## Use an icon

```tsx title="app/page.tsx"
import { HugeiconsIcon } from "@hugeicons/react";
import { Search01Icon } from "@hugeicons/core-free-icons";

export default function Page() {
  return <HugeiconsIcon icon={Search01Icon} size={20} color="currentColor" strokeWidth={1.5} />;
}
```

### With Beam UI

Beam UI wraps the same icons in one `Icon` component with fixed sizes:

```bash
npx usebeam add ui/icon
```

```tsx
import { Search01Icon } from "@hugeicons/core-free-icons";
import { Icon } from "@/components/ui/icon";

<Icon icon={Search01Icon} size="sm" />
```

Every icon in [Browse](/docs/icons/browse) works the same way: copy its name and pass it as `icon`.
